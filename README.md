# **README.md — AdventureWorks.WCFgRPC.NTTECO.Usecase**

## **Overview**
This repository is an **eye‑opening modernization usecase** demonstrating the development effort, architectural friction, and protocol‑specific complexity involved in migrating traditional **WCF** services toward **gRPC**.  
It is intentionally minimal, intentionally raw, and intentionally honest.

The goal is simple:

> **Expose the real‑world complexity of WCF → gRPC modernization and highlight why NTTECO exists as the alternative architectural category.**

This repository contains **no NTTECO implementation**.  
NTTECO is referenced only as a **modernization usecase category**, not as a migration tool.


## **What is NTTECO?**
**NTTECO is the Metadata‑Driven Object Graph Authority Platform — the architectural category designed to eliminate accidental complexity in distributed systems.**

NTTECO provides a unified model for:

- deterministic transport envelopes  
- canonical serialization  
- runtime context propagation  
- structured metadata authority  
- predictable object graph boundaries  
- envelope‑driven service orchestration  
- context‑safe multi‑segment UI workflows  

NTTECO is **not**:

- a migration tool  
- a converter  
- a modernization utility  
- a WCF wrapper  
- a gRPC adapter  
- a code generator  

Instead, NTTECO represents a **modernization usecase category** — a fundamentally different architectural approach that advances software development by removing layers of boilerplate code, redundant DTOs, mapping logic, and protocol‑specific infrastructure.

Learn more at **[https://ntteco.com](https://ntteco.com)**.

## **Repository Structure**
This repository includes:

- **WCF Services**  
  Minimal implementations showing legacy service boundaries, configuration overhead, and SOAP‑driven DTO structures.

- **gRPC Services**  
  Proto definitions, service contracts, and client implementations illustrating the migration friction and protocol‑specific boilerplate.

- **Shared Entities (AdventureWorks)**  
  Simplified EF6 entity mappings for Person, Product, and WorkOrder.

- **WinForms Client (Optional)**  
  Demonstrates the client‑side complexity of consuming both WCF and gRPC services.

- **No NTTECO Code**  
  NTTECO is referenced only as a modernization usecase category.
